# Search review development settings

User-authorized 2026-09-12 repair and smoke campaign. The development profile selects a separately hashed metadata inventory in which only search_messages.critic_required changes from false to true. Search queries may be syntactically valid and grounded while irrelevant to visible user intent; this setting routes them through the existing Critic check. It adds review cost and does not guarantee better task success. Risk/effect/prerequisites and the original baseline metadata remain unchanged.

The reflection smoke config selects both metadata and its manifest explicitly. The runtime verifies inventory/content hashes and records selected files in its run manifest. Policy/Critic/Revision ceilings remain 512/768/512. This is development evidence, not formal calibration. The next run combines approved contract repairs and this setting, so comparison with an earlier run does not isolate the setting's causal effect.
